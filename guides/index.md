# Smart-glasses buying and use-case guides

GlassesResearch generates focused buying and use-case guides from the verified canonical model database. Unknown capability fields never qualify a model for a shortlist.

The public build contains twelve guides generated from the living catalog, covering prescription compatibility, camera-free glasses, displays, audio, visual AI, developer access, open source, offline operation, custom AI, calls and music, video recording, and Bluetooth.
