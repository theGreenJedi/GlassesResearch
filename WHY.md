# Why GlassesResearch Exists

Smart-glasses knowledge is fragmented across vendor pages, retail listings, apps, forums, videos, regulatory databases, private experiments, and disappearing community posts. GlassesResearch exists to gather that material, test it, preserve it, and make it useful.

This project serves two equal purposes:

1. A public, community-focused knowledge base for the W610 and related W6xx ecosystem.
2. A canonical research library that lets future investigations build on prior discoveries instead of repeatedly rediscovering them.

## What we value

- Evidence over marketing
- Reproducible observations over folklore
- Attribution over appropriation
- Preservation over link rot
- User control over vendor lock-in
- Clear uncertainty over false confidence
- Useful questions as well as finished answers

## What success looks like

A newcomer should be able to identify a device, understand what is known, see what remains uncertain, find the original evidence, reproduce key experiments, and discover where to continue researching.

The repository is not merely a code host. It is intended to become a durable technical reference and a shared engineering notebook for an otherwise poorly documented hardware ecosystem.
