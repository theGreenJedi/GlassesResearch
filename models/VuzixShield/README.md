# Vuzix Shield

Vuzix Shield belongs to the company's standalone Android wearable-computer branch.

## Architecture and development

Vuzix's current developer documentation lists Shield among standalone devices that do not require an outside connection. Standard Android APIs are available, and Vuzix's Connectivity SDK and HUD Action Menu SDK explicitly include Shield support.

Vuzix View also lists Shield among devices that can be mirrored and controlled from a computer with USB debugging enabled, including APK installation by drag-and-drop.

## GlassesResearch significance

Shield strengthens the evidence that Vuzix maintains a multi-model Android application platform rather than isolated proprietary appliances. That is relevant to Openness, Owner Control, Cloud Independence, and Hackability, while still leaving model-specific firmware and licensing questions open.
