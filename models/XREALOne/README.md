# XREAL One — GLS-0074

Tethered XR display glasses built around USB-C DisplayPort input and XREAL's X1 spatial-computing chip.

## Hardware and host model

XREAL's official One-series documentation establishes that the glasses are fundamentally a wired display device rather than a standalone Android computer. Compatible hosts provide video through USB-C DisplayPort Alt Mode and also provide power.

The primary specifications describe:

- Sony Micro-OLED display;
- 1920 × 1080 resolution per eye;
- up to 120 Hz refresh rate;
- approximately 50° field of view;
- electrochromic dimming;
- Bose-tuned open-ear audio;
- XREAL X1 spatial-computing processor;
- USB-C DisplayPort video/data path.

The One family supports built-in spatial display modes without requiring the older Beam accessory for every spatial function.

## Development and firmware

XREAL publishes an SDK built around Unity XR Plugin, XR Interaction Toolkit and AR Foundation. Separate One-series documentation covers host connection, operation and firmware updates.
