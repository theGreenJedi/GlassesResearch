# Vuzix LX1

Vuzix LX1 belongs to the company's standalone Android wearable-computer branch.

## Architecture and development

Vuzix's developer documentation lists LX1 with the M400, M4000, Blade 2, and Shield as a standalone device that does not require an outside connection. Vuzix recommends Android development and provides platform SDKs and support resources around its wearable devices.

Vuzix View supports LX1 for screen mirroring/control, keyboard input, screenshots, log retrieval, and APK installation over USB debugging.

## GlassesResearch significance

LX1 helps define the breadth of the Vuzix Android lineage and should not be conflated with the phone-driven Z100 architecture. Its presence in the same standalone branch matters for lineage mapping and for future comparison of owner-controlled application deployment across Vuzix hardware.
