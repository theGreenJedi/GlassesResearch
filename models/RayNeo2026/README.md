# RayNeo iO / GT / GT Max — 2026 availability hub

**Technology lineage:** [RayNeo / TCL / Thunderbird](../../lineages/RAYNEO_TCL.md)

This hub preserves the three RayNeo products that moved from verified release-tracker status into canonical purchasable-model status on the September 4–5, 2026 availability boundary.

## RayNeo iO — GLS-0185

**Category:** discreet display / AI smart glasses  
**Acquisition evidence:** current first-party store with checkout and prescription ordering  
**Evidence state:** manufacturer-primary; independent/NDI verification pending

RayNeo currently describes iO as approximately 33 g everyday display eyewear with a transparent information display and AI/translation/productivity functions. GlassesResearch does not inherit X2/X3 Pro camera, Android, ADB, firmware or cloud-survival properties into iO.

Research queue: display architecture, phone/app requirements, storage, radio stack, offline residue, account dependency, firmware updates, developer access, prescription serviceability and service-loss behavior.

Primary: https://www.rayneo.com/products/rayneo-io-ai-glasses

## RayNeo GT — GLS-0186

**Category:** host-driven XR display / native 3DoF  
**Acquisition evidence:** current first-party checkout  
**Evidence state:** manufacturer-primary; optical/interoperability verification pending

RayNeo's own GT-family comparison lists GT at 46° FOV and approximately 68 g with native 3DoF. Its report card must be built from GT-specific evidence rather than copied from Air-family glasses.

Research queue: generic DisplayPort behavior, Zone 360 tracking, firmware, host compatibility, optical clarity/eyebox, audio, spatial-mode persistence and prescription/fit constraints.

Primary: https://www.rayneo.com/pages/rayneo-gt-series-ar-glasses

## RayNeo GT Max — GLS-0187

**Category:** host-driven XR display / native 3DoF  
**Acquisition evidence:** current first-party checkout  
**Evidence state:** manufacturer-primary; optical/interoperability verification pending

GT Max is sold as separate hardware from GT. RayNeo claims a 59° FOV, approximately 76 g weight and three precision IPD size classes, with larger virtual-display modes than GT.

Research queue: verify FOV/PPD tradeoff, IPD sizing, edge clarity, host compatibility, 3DoF behavior, firmware, long-session comfort and prescription constraints.

Primary: https://www.rayneo.com/pages/rayneo-gt-series-ar-glasses
