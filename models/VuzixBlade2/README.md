# Vuzix Blade 2 — GLS-0055

Monocular enterprise smart glasses in Vuzix's standalone Android developer lineage.

## Architecture and development

Vuzix groups Blade 2 with its standalone Android devices. Its support site maintains a dedicated development guide, sample project, Speech SDK, Barcode SDK, phone-app communication documentation, Unity guidance, device-interface documentation, and downloadable developer resources.

Vuzix's current Blade/Blade 2 downloads include Speech Recognition Service documentation, Haptic Feedback API documentation, HUD Resources, HUD Action Menu resources, and an Android Studio device profile.

## GlassesResearch significance

Blade 2 deserves separate treatment from Z100 because applications execute on the glasses rather than on a paired phone. It also provides unusually concrete evidence for supported Android development and HUD-oriented application tooling.

No report-card grade is assigned until model-specific capability and ownership constraints are evaluated.
