# Snap Spectacles (5th Gen, 2024) — GLS-0068

Standalone AR glasses distributed through Snap's developer program.

## Development platform

Snap publishes a dedicated Spectacles developer environment rather than treating the device as a closed consumer accessory. The current platform includes Lens Studio tooling, device APIs, samples, packages, compatibility documentation and a publishing/deployment path for Spectacles applications.

The official feature documentation exposes capabilities including:

- camera-frame access;
- gesture and hand interaction;
- world-query / spatial APIs;
- HTTP networking;
- controller and input integration;
- Spectacles-specific packages and modules.

Snap also publishes an API compatibility list and public sample-code repository, making this generation materially more inspectable from a developer perspective than many camera/audio consumer glasses.
