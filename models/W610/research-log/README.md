# W610 Research Log

This section holds the chronological record of W610 experiments, observations, acquisitions, source discoveries, and decisions.

Use one file per session or significant event, named `YYYY-MM-DD-short-description.md`.

## Session template

```markdown
# YYYY-MM-DD — Title

## Objective

## Device and environment

## Procedure

## Observations

## Evidence

## Interpretation

## Confidence and limitations

## Next actions
```

The research log may contain provisional findings. Promote stable conclusions into the relevant W610 topic section while retaining the original dated entry.
