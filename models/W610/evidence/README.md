# W610 Evidence Archive

Use this section for model-specific photographs, manuals, packaging, retail listings, regulatory records, QR-code documentation, raw captures, logs, measurements, and preserved source material.

## Suggested layout

- `photos/`
- `manuals/`
- `retail-listings/`
- `regulatory/`
- `captures/`
- `logs/`
- `measurements/`

Preserve provenance: source, acquisition date, original filename, hash where useful, and any redactions. Remove order details, addresses, account identifiers, credentials, and unrelated nearby-device data before publication.
