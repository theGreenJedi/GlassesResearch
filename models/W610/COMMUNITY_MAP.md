# W610 Community Resources

This is the **W610 / HeyCyan-specific appendix** to the site-wide [Community & Development Hub](../../resources/COMMUNITY_AND_DEVELOPMENT.md). GlassesResearch is not W610-centric; ecosystem-wide communities and development resources belong in the global hub.

This page contains **direct links to real W610/HeyCyan resources**. It does not list generic places to search or empty research targets.

## Development projects

- [HeyCyanSmartGlassesSDK — GitHub](https://github.com/ebowwa/HeyCyanSmartGlassesSDK) — cross-platform HeyCyan SDK and BLE implementation with W610-tagged code and documentation for device information, media control, Wi-Fi transfer, iOS, and Android.
- [CyanBridge / Alternative HeyCyan App and SDK — GitHub](https://github.com/FerSaiyan/Alternative-HeyCyan-App-and-SDK) — open alternative Android companion stack for HeyCyan-compatible glasses.
- [CyanBridge releases](https://github.com/FerSaiyan/Alternative-HeyCyan-App-and-SDK/releases) — downloadable releases, APKs, integrity hashes, release notes, Wi-Fi Direct media-transfer details, and local-AI work.
