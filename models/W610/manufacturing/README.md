# W610 Manufacturing Intelligence

This section maps OEM, ODM, supplier, brand, app-operator, and reseller roles without collapsing them into unsupported claims.

## Current leads

- [ORG-0002 — Goodway Techs](../../../glossary/organizations/ORG-0002-goodway-techs.md) publishes a detailed W610 product page and is a strong commercial-source lead.
- [ORG-0003 — Dongguan Zhiyang Electronic Technology](../../../glossary/organizations/ORG-0003-dongguan-zhiyang.md) markets a W610-labelled OEM/ODM product.
- [ORG-0001 — Shenzhen Qingcheng Future Technology](../../../glossary/organizations/ORG-0001-hecyan-qingcheng-future.md) is confirmed as the HeyCyan app operator, not yet as the hardware manufacturer.
- Multiple retail names repeat the same chipset, camera, battery, and app fingerprint, supporting a shared platform or rebranding ecosystem.

## Working conclusion

The W610 should currently be treated as a multi-brand OEM/reference-platform family. Exact design ownership, factory responsibility, and revision lineage remain unresolved.

## Next evidence

1. Compare packaging, manuals, QR destinations, product images, dimensions, and button layouts across brands.
2. Preserve supplier names, addresses, MOQ, certifications, and archived pages.
3. Search FCC, Bluetooth SIG, patents, trade-show records, and corporate registries using every known alias.
4. Confirm relationships with device-level evidence before promoting claims.
