# Rokid AI Glasses Style — active investigation

Rokid AI Glasses Style are display-free camera/audio AI glasses introduced into Rokid's current global lineup in 2026. They are a **distinct eyewear model** from display-equipped Rokid Glasses, not merely a bundle or colorway.

**Technology lineage:** [Rokid](../../lineages/ROKID.md)  
**Catalog state:** investigation / registry candidate; no new stable `GLS-####` ID assigned by this page  
**Evidence state:** current first-party manufacturer documentation; hands-on verification pending

## Manufacturer-documented hardware

Current Rokid documentation, checked 2026-09-05, describes:

- approximately **38.5 g** frame weight without prescription lenses;
- TR90 frame with titanium-alloy hinges;
- **12 MP Sony IMX681** wearer-view camera;
- 3024 × 4032 still capture and video up to 3K at 30 fps;
- 109° camera field of view and f/2.25 aperture;
- four-microphone directional array with noise reduction;
- dual directional open-ear AAC speakers;
- 32 GB flash storage;
- Wi-Fi 6 and Bluetooth 5.3;
- IPX4 splash resistance;
- Qualcomm AR1-class compute claimed in Rokid's lineup comparison;
- voice, touch, and head-gesture interaction;
- no in-lens display.

Rokid states that prescription lenses fit directly into the Style frame and advertises a broad prescription/lens-option range. Exact optical-service availability varies by prescription and region and should be verified independently before it is treated as universal.

## Software and service boundary

Rokid states that the Hi Rokid / Rokid AI companion app is required for pairing, settings, media management, and updates. AI responses, navigation, and translation are delivered through open-ear audio and the app rather than an in-lens display.

This makes Style a useful comparison against Meta-style camera/audio eyewear, but its service-survival profile must be tested rather than inferred from Rokid Glasses. Shared branding, chipset family, and companion software do not prove identical offline behavior or SDK exposure.

## Style Pack identity

**Rokid AI Glasses Style Pack is not a second glasses model.** Rokid's current collection describes the Pack as the same Style eyewear sold with additional power/accessory capacity. GlassesResearch should preserve the Pack as a retail configuration while counting the underlying Style glasses once.

## Investigation queue

1. Confirm chipset, RAM, storage partitioning, battery capacity, and sensor inventory from model-specific technical material or hands-on inspection.
2. Determine which functions work after initial setup with network access removed.
3. Test capture behavior, recording indicator behavior, file export, metadata, and local storage access.
4. Map companion-app permissions, account requirements, endpoints, update behavior, and data retention.
5. Determine whether Rokid's terminal/glasses SDK explicitly supports Style and which APIs are exposed.
6. Check ADB, USB, Bluetooth services, Wi-Fi services, firmware packages, update manifests, and recoverability paths.
7. Verify prescription-lens serviceability with ordinary optical shops and regional constraints.
8. Compare Style directly with Rokid Glasses on wearability, battery, privacy, owner control, cloud independence, and service-loss residue.
