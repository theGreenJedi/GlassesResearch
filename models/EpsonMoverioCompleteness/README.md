# Epson Moverio completeness additions

**Technology lineage:** [Epson Moverio](../../lineages/EPSON_MOVERIO.md)

This hub covers the Moverio identities exposed by the 2026-09-05 whole-manufacturer audit.

## Moverio BT-350 — GLS-0189

**Category:** standalone binocular AR smart glasses  
**Manufacturer model:** `V11H837020`  
**Catalog state:** legacy / enterprise-commercial

Epson's surviving product page identifies BT-350 as adjustable smart glasses built for multi-user deployments, using Moverio OS, onboard Intel Atom compute, camera/sensors, wireless connectivity, storage and Moverio developer tooling. Its fleet-oriented design and model number establish a distinct product identity from BT-300.

Primary: https://epson.com/For-Work/Wearables/Smart-Glasses/Moverio-BT-350-Smart-Glasses/p/V11H837020

## Moverio BT-30E — GLS-0190

**Category:** tethered binocular display smart glasses  
**Catalog state:** legacy / region-limited  
**First-party release record:** November 2018

Epson's Japanese support record preserves BT-30E as its own released product with dedicated firmware history. Epson's technical documentation groups BT-30E with BT-35E in the monitor-model branch but does not make them the same physical product.

Primary: https://www.epson.jp/support/portal/hoshu/bt-30e.htm

## Adjacent industrial systems

- `ADJ-0011` — **Moverio Pro BT-2000**, industrial smart headset with headband/forehead-pad architecture.
- `ADJ-0012` — **Moverio Pro BT-2200**, industrial smart headset designed for use with safety helmets.

These are historically important Moverio systems, but GlassesResearch routes them outside the eyeglass count because their primary physical interface is an industrial head-worn support/helmet system.
