# Ray-Ban Meta (Gen 2) — GLS-0003

Camera-and-audio smart glasses from Meta and Ray-Ban, released in 2025.

## What the official documentation establishes

- Conventional eyewear form factor with integrated camera, open-ear speakers and a five-microphone array.
- 32 GB flash storage.
- Bluetooth plus an internal Wi-Fi connection used for higher-bandwidth media import and firmware updates.
- Meta AI is the companion application and AI service.
- Pairing and normal device management are performed through the Meta AI app.
- Meta documents up to 8 hours of moderate use and up to 5 hours of continuous audio streaming/voice assistance for the current generation.
- Manufacturer documentation supports prescription-lens options on supported frames.

## Camera and media

Ray-Ban's current product documentation lists still capture up to 3024 × 4032 and video up to 2203 × 2938 at 30 fps for the current Ray-Ban Meta generation.

Media can be imported from the glasses into the Meta AI app. Ray-Ban documents a temporary direct Wi-Fi connection for transfers that need more bandwidth, including media import and firmware updates.

## AI and cloud dependence

Meta's multimodal system documentation describes Ray-Ban Meta requests such as “look and tell me” as sending captured visual input and transcribed speech to Meta's AI model for processing. The glasses therefore provide a useful reference case for cloud-assisted visual AI rather than a fully local inference architecture.
