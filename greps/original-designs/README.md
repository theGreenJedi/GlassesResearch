# Original GREP design specifications

These files preserve the pre-typesetting design specifications that established the current three GREP progenitors.

- [GREP-42 — NDI / Controlled Inspection](GREP-42-DESIGN.md)
- [GREP-44 — Comprehensive Owned-Device Investigation](GREP-44-DESIGN.md)
- [GREP-46 — Real-World Experience and Use Cases](GREP-46-DESIGN.md)

They are retained as design-history references. The current printable bench forms live one level up in [`greps/`](../README.md).

When a printable revision differs from these specifications, the difference should be deliberate and documented rather than silently rewriting the historical design intent.
