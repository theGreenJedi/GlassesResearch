# Research Library

A cross-ecosystem library of directly identifiable sources used by GlassesResearch. Each entry has a stable `EV-####` ID in [`resources.json`](resources.json).

## Current coverage

- W610 / HeyCyan — SDKs, alternative companion software, release discussions, FCC records and supplier specifications;
- Brilliant Labs Frame — hardware manual, SDK, Bluetooth specification and firmware source;
- MentraOS / open smart-glasses hardware — operating-system source, releases and open hardware;
- Vuzix Z100 — manuals and SDK documentation;
- Snap Spectacles — developer portal, API compatibility information and sample code;
- XREAL One — SDK and primary specifications;
- RayNeo X3 Pro — public application/source and device-development examples;
- Rokid Glasses — specifications and SDK documentation;
- Solos AirGo — current cross-model developer SDK;
- Ray-Ban Meta — operational support documentation and Meta's multimodal-AI system documentation;
- Even Realities G2 — specifications and support documentation;
- Android XR — official development and OpenXR documentation.

## Evidence types

**Regulatory primary** records come from government or standards filings tied to an identified device. **Vendor primary** records come from the manufacturer or platform owner. **Community primary** records are originating public projects, repositories, or releases. **Community report** records are specific attributable discussions or reports. **GlassesResearch verified** identifies observations or tests reproduced by this project.
