# Service Dependence Framework

Cloud Independence should be measured function by function rather than inferred from whether a product has a companion application.

For each model, document what remains available when internet access is absent, the companion device is absent, the user is signed out, or a manufacturer service is no longer available when historical evidence permits.

Track basic startup, pairing, media capture, audio, display functions, file transfer, controls, applications, AI features, and configuration separately. Also document normal first-run requirements such as an account, companion application, permissions, network access, updates, regional requirements, and paid service requirements.

A product can remain locally useful while optional intelligence features require a service; another can lose most functionality when its service disappears. Preserve that distinction. These findings directly support Cloud Independence, Owner Control, Software, and discontinued-device survivability.
