# AI Feature Taxonomy

The label AI glasses is too broad for useful comparison. Research should describe the functions a product can actually provide.

Track functions separately, including voice assistance, image question answering, scene description, text recognition, translation, object recognition, reminders or memory, navigation assistance, conversational context, visual search, media assistance, accessibility functions, and support for third-party models.

For each function identify where input is captured, where processing is documented to occur (glasses, companion device, manufacturer service, third-party service, or unknown), whether network access is required, and the user-visible output route such as audio, display, companion device, or haptic feedback.

Distinguish advertised functions, documented implementation, independent observation, and GlassesResearch verification. A camera plus a voice assistant does not by itself establish Visual AI; evidence should show that visual input participates in the function.

Also record whether the owner can select a model or service, supply credentials, use local processing, or replace the default assistant. These findings inform Visual AI, Software, Owner Control, Cloud Independence, and Hackability.
