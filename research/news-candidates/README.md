# Daily News Candidate Store

This directory is the repository-side intake layer for the GlassesResearch news collector. It is intentionally **not part of the public website navigation**.

The daily collector records potentially material ecosystem developments here before they are promoted into public research. A candidate is not a verified claim merely because it appears in this directory.

## Promotion rule

News is an input to the research institution, not the final product. When a candidate is materially relevant and supported well enough to publish, update the durable research that it affects:

- `models/THE_LIST.md` for new or materially changed purchasable models
- `lineages/` for lineage developments, compatibility, shared software/protocols, or ecosystem changes
- model chapters for model-specific facts
- `docs/INDUSTRY_TIMELINE.md` / timeline data for significant milestones
- `docs/news/` for public news synthesis
- `resources/COMMUNITY_AND_DEVELOPMENT.md` for community/developer ecosystem changes
- comparison data for newly comparable facts
- glossary, FAQ, artifacts, and evidence records where applicable

The collector should never silently turn an unverified candidate into a canonical fact.
