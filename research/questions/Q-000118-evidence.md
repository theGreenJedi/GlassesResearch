# Q-000118 — Vuzix Speech SDK language support

Research reviewed: 2026-10-24. **Observed source:** [Stack Overflow question 60778715](https://stackoverflow.com/questions/60778715/vuzix-speech-sdk-language-support), asked 2020-03-20. Original question explicitly asks how an M300 Android app can recognize German number words and where to load language-recognition files. Registry entry Q-000118 was discovered from Stack Exchange; this is not a fabricated query.

**Disposition:** Evidence-qualified answer published in `docs/faq/09-development-openness.md` via merged PR #685; live production page independently proven against the deployed build digest on 2026-10-24. Manufacturer sources establish a localized M300 speech interface and German support in Vuzix's broader command engine. They do not independently establish the German-language resource installation process for every M300 firmware. Preserve this distinction.

## Claim-level provenance

1. **M300/M300XL speech SDK localizes wake words to the selected device language and supports custom phrases/vocabulary inspection.** Primary: [Vuzix, Getting Started Code, M300/M300XL SDK](https://support.vuzix.com/docs/getting-started-code-4), retrieved 2026-10-24. The page explicitly names M300 and M300XL for localized wake words, and demonstrates `insertPhrase`/`dump` vocabulary diagnostics. Documentation, not physical-device testing.
2. **Vuzix speech-command engine lists German as supported.** Primary: [Vuzix, Speech Command Overview](https://support.vuzix.com/docs/overview-32), updated 2025-08-06, retrieved 2026-10-24. Scope is Vuzix speech-command documentation; do not assume the list is a guaranteed capability on every legacy M300 OS revision.
3. **Change the glasses' system language; language resources may load automatically; a reboot may help; an English device locale can reject German phrases.** Independent developer experience: [Stack Overflow answer by Vincent Guigui (2020-04-10) and comment by Brent K. (2021-03-31)](https://stackoverflow.com/questions/60778715/vuzix-speech-sdk-language-support). These are unverified community observations, not official support instructions or measured recognition performance.
4. **28-language OS 2.5 release is for M400/M4000.** Primary: [Vuzix press release (2022-04-29)](https://ir.vuzix.com/news-events/press-releases/detail/1966/vuzix-m-series-smart-glasses-now-fully-support-28-languages). Independent trade coverage: [Speech Technology Magazine (2022-05-02)](https://www.speechtechmag.com/Articles/News/Speech-Technology-News/Vuzix-Expands-Language-Support-152738.aspx). Explicitly exclude this release as proof of M300 firmware or language-file availability.
5. **No confirmed public M300 German language-file download or manual installation procedure in the sources reviewed.** Absence-of-evidence conclusion, not a claim that files do not exist. Official [Vuzix Speech SDK knowledge base](https://support.vuzix.com/docs/working-with-the-speech-sdk) is the escalation point; a device/firmware-specific vendor response is needed before prescribing file placement or sideloading.

## Uncertainty, safety, and follow-up

No GlassesResearch M300 hardware or firmware test. Actual recognition of German number words, vocabulary behavior across locale switches, accuracy, and whether particular firmware requires extra resources remain unverified. Do not recommend downloading unknown recognition files or changing system partitions. Recheck if Vuzix supplies M300-specific documentation or a reproducible device test. No redistribution of SDK binaries or vendor manuals; links only. Registry publication follows the successful merge and independent live-content proof below.
