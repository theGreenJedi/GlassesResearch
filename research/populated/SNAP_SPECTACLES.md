# Snap Spectacles — populated research record

## SPECS / 2026 consumer generation — GLS-0146

Snap opened SPECS preorders on June 16, 2026 at $2,195 with a $200 refundable deposit and a fall shipping target for the United States, United Kingdom and France. Primary documentation describes a standalone 132–136 g binocular AR system with a 51° full-color display, dual Snapdragon processors, four-hour mixed-use claim, charging case, prescription inserts, electrochromic lenses, Snap OS, Lens Studio and a Native Development Kit. Shipment and independent performance remain unresolved. See [EV-0059](../../evidence/EV-0059-Snap-SPECS-primary-preorder.md).

Primary evidence: official developer portal (`EV-0018`), API compatibility list (`EV-0019`), sample code (`EV-0020`) and `docs/report-cards/BATCH_01.md`.

## Spectacles 5 / 2024 generation — GLS-0068
Standalone developer AR platform. Snap documents see-through stereo waveguides, LCoS projectors, 46° FOV, 37 pixels/degree, 6DoF tracking, hand tracking, voice input, stereo audio, six microphones, dual Snapdragon compute, two color cameras, two infrared CV cameras, IMUs, Wi-Fi 6, Bluetooth, GNSS, ~226 g mass and roughly 45 minutes continuous runtime.

Report-card anchor: H9.0 W4.5 VAI9.0 S9.0 O7.5 OC7.0 CI7.0 Hack7.5 HUD9.0; Value not yet graded/developer-program economics not directly retail-comparable.

## Developer surface
Lens Studio, Snap OS, developer kits, compatibility matrices, sample code and experimental camera/microphone/location/network permissions form a mature supported development stack. This supports high application-level Openness/Hackability but not unrestricted firmware, bootloader, replacement OS or hardware-level ownership.

## Visual AI / sensing
Multiple outward-facing color/IR cameras, IMUs and supported experimental permissions make computer vision/spatial context a core capability. Visual AI therefore scores highly on evidence, unlike products where a camera exists only for capture.

## Wearability tradeoff
At ~226 g and ~45 minutes continuous runtime, this generation is a developer wearable computer rather than ordinary all-day eyewear. Strong hardware/HUD scores must not erase that wearability constraint.

## Cloud and account dependence
The glasses can run standalone local experiences, while development/distribution and many Snap ecosystem workflows remain platform-connected. Exact account requirements, offline runtime boundaries and service-shutdown survival need function-by-function testing.

## Research priorities
Firmware/bootloader state, unrestricted sensor limits, prescription/optical support, repairability, battery aging, exact offline runtime behavior, platform-access economics and long-term developer-program survival.
