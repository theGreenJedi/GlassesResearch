# Populated Research Index

This directory is the normalized evidence-backed research layer for GlassesResearch. It sits between raw/source research and public editorial prose.

A populated record should preserve model/lineage boundaries, report-card anchors where available, ownership implications, lifecycle/service dependence, and explicit unknowns. It must not invent missing specifications or silently copy facts across visually similar generations.

## How this layer is used

1. **Evidence first.** Populate from primary/regulatory/community evidence and completed report-card research.
2. **Model boundaries stay explicit.** A corporate lineage can contain radically different architectures.
3. **Unknown stays unknown.** Absence of evidence is not converted into `no`, unsupported, or a low score.
4. **N/A is semantic.** Use it only where a dimension genuinely does not apply, such as Visual AI on camera-free audio glasses or HUD on screen-free products.
5. **Ownership is multidimensional.** Application SDK access, firmware access, cloud independence, repairability and assistant replacement are separate claims.
6. **Later standardized calibration wins.** If an older report-card batch and a later common-ruler batch assign different numeric scores, preserve the later standardized score and retain older descriptive evidence rather than silently mixing calibrations.
7. **Editorial prose comes downstream.** Public model summaries and comparisons should be generated from populated evidence, not used as the source of truth.

## Next mission layer

With the completed lineage/report-card packets normalized, remaining work should shift from bulk conversion to targeted evidence acquisition: exact offline survival, prescription/optical serviceability, battery normalization, repairability, firmware/protocol access, regional/version variance, current value, and lifecycle/service-shutdown evidence. These fields can then feed comparison filters, report cards, model prose, genealogy maps and the discontinued-product archive.
