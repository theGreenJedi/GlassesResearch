Source basis: `docs/report-cards/HIGH_THROUGHPUT_BATCH_03.md`, `HIGH_THROUGHPUT_BATCH_04.md`, and cited VITURE primary sources.

## Lineage pattern
VITURE One → One Lite → Pro → Luma / Luma Pro / Luma Ultra, with Beast as a high-performance display branch. These are primarily host-driven XR/display glasses: Visual AI is N/A unless a separate sensing stack is explicitly documented. Practical Owner Control and Cloud Independence are high because the user chooses the host/content stack.

## Software / ownership
SpaceWalker and host interoperability create strong practical owner control. Ultra's spatial development surface is a meaningful openness increase, but none of this implies open firmware/hardware. Core display use remains locally host-driven rather than vendor-cloud dependent.

## Optical serviceability
Built-in myopia adjustment is useful but not equivalent to comprehensive prescription service. Exact correction ranges, astigmatism support, inserts, independent optical service and IPD/fit constraints remain model-specific.

## Research priorities
Current/legacy price checks, exact host compatibility, Ultra spatial API scope, firmware/update behavior, repairability, myopia/IPD limits, prescription options, long-duration wear and accessory dependence.
