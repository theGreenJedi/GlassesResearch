# Meta wearable developer ecosystem — community bridges and web-app tooling

## Meta Wearables Web App AI Toolkit

Meta's public `facebook/meta-wearables-webapp` repository provides AI-assisted development tooling for Web Apps rendered on Meta Ray-Ban Display glasses. It targets standard HTML/CSS/JavaScript and includes integration material for Claude Code, Codex, Cursor and GitHub Copilot, plus a public Wearables MCP documentation server.

Primary source:

- https://github.com/facebook/meta-wearables-webapp

This is evidence of a broader **vendor-supported development surface**. It is not evidence of open firmware, unrestricted hardware ownership, service survival or cloud independence.

## SpecBridge / MetaBridge

The public `jmdurant/MetaBridge` repository describes **SpecBridge**, an open-source iOS bridge between Ray-Ban Meta glasses, Meta's Device Access Toolkit and standard RTMP/Twitch streaming infrastructure.

Community source:

- https://github.com/jmdurant/MetaBridge

**Provenance:** community/open-source implementation. The repository is useful evidence that third parties are already building practical bridges on the vendor SDK, but GlassesResearch has not independently reproduced its operation.

## Research interpretation

Together these projects strengthen a useful distinction:

**programmable through a vendor-supported surface ≠ open hardware or owner sovereignty.**

Track practical third-party applications because they reveal what the SDK permits in reality. Continue scoring Openness, Owner Control, Cloud Independence and Hackability independently.
