# W100 / Ear Dance lineage

The **W100 / Ear Dance** family is a commodity audio-and-translation smart-glasses platform that appears under multiple retail brands. These names are valuable search identities, but they should not automatically increase the canonical model count when the evidence points to the same underlying platform.

## Platform fingerprint

Current W100 documentation converges on the same core pattern:

- low-power **AB5712F** controller
- Bluetooth LE 5.4/6.0-class connectivity depending on seller documentation
- two roughly **85 mAh** cells (about 170 mAh total)
- open-ear speakers and microphone
- magnetic charging
- **Ear Dance** companion app
- AI/real-time translation features supplied primarily through the phone/app
- no native eyewear display

The exact seller package, lenses, firmware revision, waterproof claim, Bluetooth-version claim, and advertised language count can vary. A shared lineage is therefore **not** a claim that every branded unit is byte-for-byte identical.

## Owner guidance

If the name on the box is **EarlySincere**, **Vital Smart Glasses**, **Astrum W100**, **TG-W100**, **LEEDOAR W100**, or another seller name that resolves here, start troubleshooting and compatibility research with the **W100 / Ear Dance** platform identity. Preserve the seller name when reporting variant-specific behavior, because firmware, frame construction, lenses, packaging and accessories may differ.

## Counting rule

Retail brands and aliases in this table do **not** each become new canonical models merely because a seller changes the name. A new canonical identity requires evidence of materially distinct hardware/product generation or another catalog-admission basis under the GlassesResearch research standards.
