# Brilliant Labs Lineage — Populated Research Fields

This pass applies the GlassesResearch research framework to Brilliant Labs while keeping each generation separate. Current evidence is strongest for Frame.

## Models

- Monocle — GLS-0050
- Frame — GLS-0051
- Halo — GLS-0052

Shared company lineage does not mean identical hardware, firmware, displays, sensors, or accessories.

## Frame evidence base

Primary sources already in the GlassesResearch evidence library:

- EV-0009 — Frame hardware manual
- EV-0010 — Frame SDK
- EV-0011 — Frame Bluetooth specification
- EV-0012 — Frame public codebase

## Connectivity

Frame has official Bluetooth documentation and official SDK support. This gives GlassesResearch direct primary evidence for developer-facing connectivity rather than relying only on product marketing.

Monocle and Halo should retain their own model-specific connectivity records until equivalent sources are attached.

## Hardware and sensing

EV-0009 provides primary hardware documentation for Frame. EV-0010 documents developer-facing capabilities. Hardware presence and developer access should remain separate fields.

## Software openness

Frame has unusually strong documentation coverage: official SDK material, public Bluetooth documentation, hardware documentation, and a public codebase. This strongly supports high Openness and Owner Control ratings.

Public source does not automatically establish every other ownership property. Cloud dependence, repairability, and independent servicing remain separate questions.

## Cloud and service dependence

Frame appears structurally more survivable than products whose only interface is a closed companion service, but Cloud Independence still requires function-by-function testing. Display, camera, controls, applications, and AI features should each be assessed separately.

## Silicon genealogy

EV-0009 is the primary source for exact Frame component mapping. Do not apply Frame components to Monocle or Halo without exact-generation evidence.

## Manufacturer relationships

The brand/product relationship to Brilliant Labs is direct. Component and supplier relationships should be populated from primary documentation. No outside manufacturing relationship should be inferred from visual similarity alone.

## Optical serviceability

Current evidence does not yet establish ordinary prescription serviceability for Frame.

**State:** dedicated optical review required.

Monocle has a different form factor and should not inherit glasses-style assumptions. Halo should be evaluated independently.

## Battery

Primary documentation may establish design specifications, but normalized endurance testing is still needed before comparing Frame with other devices.

## Aging and serviceability

Frame's public hardware documentation makes it a strong candidate for long-term serviceability research. Documentation alone does not prove that specific parts are practical to replace or source.

Future work should distinguish identifiable parts, accessible parts, sourceable parts, community-demonstrated service, and manufacturer-supported service.

## AI capability

The Brilliant Labs lineage supports developer-oriented AI experimentation, but exact AI functions and processing location should remain generation and software-version specific.

## Report-card implications

### Frame

- Openness: very strong primary evidence.
- Owner Control: very strong developer-facing evidence.
- Cloud Independence: promising but still requires function-level verification.
- Hardware and Value: must be scored independently from openness.

### Monocle

GlassesResearch currently treats Monocle as the reference bar for openness. That benchmark should now be backed with the same field-level provenance standard used for Frame.

### Halo

Halo should not inherit Frame or Monocle ratings automatically. Populate it from exact-generation evidence.
