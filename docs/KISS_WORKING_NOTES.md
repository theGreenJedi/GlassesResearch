# KISS Working Notes

**KISS** is the working title for a future subject-independent investigation framework distilled from practices proven in GlassesResearch.

The final name or expansion of the acronym has not been selected.

## Relationship to GlassesResearch

GlassesResearch is the active laboratory and first reference implementation. It should continue investigating smart glasses without waiting for KISS to be complete.

KISS should be extracted slowly from methods that survive real use here:

```text
Investigation in GlassesResearch
        ↓
Repeated practical lesson
        ↓
Small KISS improvement
        ↓
Future investigations benefit
```

## Candidate principles already under test

- No orphan knowledge.
- No empty merges.
- Canonical glossary homes for recurring entities.
- Investigation-driven repository growth.
- Evidence, provenance, attribution, and confidence are first-class.
- Resource catalogs explain links rather than merely collecting them.
- Architecture changes only when actual work demonstrates a need.
- Important project knowledge should not remain trapped only in conversation.

## Candidate reusable entity types

These are observations, not a frozen taxonomy:

- model;
- organization;
- person;
- component;
- application;
- firmware;
- Bluetooth service or identifier;
- photograph or capture;
- document;
- standard or regulatory filing;
- repository;
- video;
- community;
- resource;
- investigation;
- finding;
- evidence;
- question;
- timeline event.

## Extraction rule

Do not generalize a GlassesResearch convention into KISS merely because it sounds elegant. Generalize it after repeated investigations demonstrate that it is useful beyond one subject.

## Future repository

A separate `KISS` repository may eventually contain the subject-independent constitution, templates, schemas, contribution workflow, and examples. Until then, this page preserves the concept without allowing framework design to delay GlassesResearch merges.
