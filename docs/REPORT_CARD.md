# GlassesResearch Report Card

The GlassesResearch Report Card evaluates smart glasses across **ten independent dimensions** rather than hiding tradeoffs inside one opaque overall score.

The purpose is practical: help people find the glasses that fit *their* priorities. Excellent hardware should not conceal weak owner control, and an open platform should not conceal poor wearability.

## The ten dimensions

| Dimension | What we measure |
|---|---|
| **Hardware** | Camera/vision, audio, microphones, battery, weight, thermals, build quality, and core physical capability. Display performance is graded separately. |
| **Wearability** | Looks like glasses, comfort, size, discretion, fit, and everyday practicality. |
| **Visual AI** | Can the glasses actually understand **what am I looking at?** This measures useful visual perception and the ability to turn what the wearer sees into machine-understandable context. |
| **Software** | App quality, stability, features, updates, integrations, and day-to-day software experience. |
| **Display / HUD** | Presence and usefulness of visual output: readability, resolution, brightness, field of view, color, monocular/binocular implementation, information density, outdoor usability, and how naturally information integrates into the wearer's view. |
| **Openness** | SDK/API access, sensor access, documentation, open-source components, and supported developer access. |
| **Owner Control** | Sideloading, replaceable AI, local processing, custom endpoints, and the owner's ability to choose the intelligence layer. |
| **Cloud Independence** | What continues working without the manufacturer's servers, account services, or cloud AI. |
| **Hackability** | BLE access, firmware access, reverse-engineering potential, sideloading paths, exposed interfaces, and community tooling. Official openness is not required if meaningful owner control can be obtained another way. |
| **Value** | Useful capability relative to purchase price. |

## Grades

Each applicable dimension receives both a **0–10 numeric score** for sorting/comparison and a familiar **letter grade** for the public report card.

| Score | Grade |
|---:|:---|
| 9.5–10.0 | A+ |
| 9.0–9.4 | A |
| 8.5–8.9 | A- |
| 8.0–8.4 | B+ |
| 7.5–7.9 | B |
| 7.0–7.4 | B- |
| 6.5–6.9 | C+ |
| 6.0–6.4 | C |
| 5.5–5.9 | C- |
| 5.0–5.4 | D+ |
| 4.0–4.9 | D |
| 0.0–3.9 | F |

The numeric score remains visible so devices can be sorted and compared without pretending that two products with the same letter grade are identical.

## N/A is not failure

A dimension that genuinely does not apply receives **N/A**, not zero and not an F.

For example, glasses designed without a HUD receive **Display / HUD: N/A**. They are not penalized as though they contain a terrible display; the report card simply makes clear that visual output is not part of that product.

**N/A dimensions are excluded from any calculated aggregate.** A missing or undocumented result is different from N/A and must not be silently converted into a failing grade.

## No universal winner

The report card is intentionally multidimensional. GlassesResearch does not assume that one overall grade answers every buyer's question.

A device can have best-in-class hardware and poor owner control. Another can have modest hardware but exceptional openness and hackability. The comparison tools should expose those differences so users can prioritize the dimensions that matter to them.

## Benchmarking

Scores are benchmark-based rather than claims of theoretical perfection. A **10** represents the best demonstrated state of the category against the current GlassesResearch benchmark. Benchmarks can evolve as the industry advances.

The anticipated 2026 Google/Android XR generation may become an important hardware benchmark once shipping products can be evaluated, but no vendor receives a score before the relevant capability is documented or tested. Hardware leadership does not imply leadership in openness, owner control, cloud independence, or hackability.

## Status

This page defines the rating framework. Product grades will be added only when there is enough information to assign them responsibly. GlassesResearch will not manufacture scores merely to fill a table.
