# Fieldwork

Fieldwork is the GlassesResearch community field-research instrument for people who own or have hands-on access to smart glasses.

**The public contribution gateway is now [Want to contribute?](CONTRIBUTE.md).** Fieldwork is one path within that broader contribution system rather than a standalone wall of documentation.

## What Fieldwork does

- Starts with a few useful hands-on questions and lets contributors go deeper only if they want to.
- Supports progressive technical fieldwork across wearability, battery behavior, software, owner control, BLE, USB, networking, and reproducible evidence.
- Welcomes anonymous contributions and treats anonymous and credited submissions under the same evidence rules.
- Uses an optional serial number only to derive a one-way device fingerprint for duplicate detection; the raw serial must never be retained, published, exported, or logged.
- Keeps community evidence distinct from GlassesResearch Verified findings. Repetition alone never promotes a report to Verified.

## Fieldwork app

A functional browser/PWA client now exists with the current 68-question instrument, local draft persistence, completion scoring, catalog-backed model lookup, privacy-preserving serial fingerprinting, and schema-valid export.

[Open the Fieldwork app](FIELDWORK_APP.md)

**Direct anonymous submission is not enabled yet.** Until the GlassesResearch-controlled submission endpoint is live, the app is a functional research client and export tool rather than a finished one-tap submission service.

For all contribution routes—including Fieldwork, corrections, source preservation, technical artifacts, and GitHub contributions—start at [Want to contribute?](CONTRIBUTE.md).

**Own glasses? Help characterize them. Five minutes is useful. Go as deep as you want.**
