# Start Here

GlassesResearch is organized around the questions people actually arrive with.

## I want to know what smart glasses exist

Start with [The List](../models/THE_LIST.md) for the broad catalog, then open model chapters for deeper research.

## I want to know what to buy

Start with the [Buyer & Openness Guide](../buyers/BUYER_AND_OPENNESS_GUIDE.md), then use [100 Questions](faq/README.md) for practical buying, battery, display, privacy, accessibility, development, and ownership questions.

## I already own a pair

Find the model in [The List](../models/THE_LIST.md). If GlassesResearch has a dedicated chapter, use that as the canonical entry point for known behavior, evidence, software, firmware, accessories, community resources, and open-development work.

## I want to hack or develop for smart glasses

Start with [Hacking & Vendor Independence](../hacking/README.md). The [Open Hacking Resource Ledger](../hacking/OPEN_HACKING_RESOURCE_LEDGER.md) indexes public SDKs, firmware leads, recovery research, protocols, hardware projects, and open-source ecosystems without presenting unverified procedures as proven.

## I want current developments

Use [Research & News](news/README.md) for releases, upgrades, availability changes, ecosystem developments, and research worth preserving.

## I am researching older or discontinued glasses

Enter the [GlassesResearch Museum](MUSEUM.md) and [Industry Timeline](INDUSTRY_TIMELINE.md).

## I need terminology or a manufacturer/component reference

Use the [Glossary](../glossary/README.md).

## I have useful information to contribute

Use [Contribute](CONTRIBUTE.md). Community reports are welcome when clearly labeled, and verified findings are promoted only when the evidence supports them.

## One rule across the whole site

A source being popular, repeated, or downloadable does not automatically make its claims verified. GlassesResearch keeps firsthand evidence, primary sources, community reports, hypotheses, historical material, and disproven claims distinct.
