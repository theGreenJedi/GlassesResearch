# Community contributors

Persistent contributor profiles are generated from accepted independent hands-on reviews. Reviewers may use a public name or pseudonym; anonymous reviews remain valid evidence but do not create a public contributor profile.

No contributor history has been populated yet because GlassesResearch does not invent or backfill reviews. This page is replaced during the site build with the current accepted-review index.

Contributor history is provenance, not an authority score. Every claim remains governed by its own evidence, device context, reproducibility, and corroboration.
