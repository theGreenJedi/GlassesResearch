# Events

A month-at-a-time calendar of launches, conferences, developer events, research meetings, standards activity, and community dates that materially affect smart glasses.

The website is the canonical event record. Dates are included only when they have a traceable public source; an event entry is not a GlassesResearch endorsement.

## How the calendar works

Events keep their original organizer/source link and verification date. Multi-day events span their real calendar dates. Past months remain browsable so announcements can later point forward to the resulting GlassesResearch model, investigation, evidence, or news record.

On small screens, the month grid is paired with a selected-day event list rather than forcing a desktop calendar into a narrow viewport.

### Event categories

**Launch** · **Conference** · **Developer** · **Research** · **Community** · **Standards / regulatory**

If an announced date changes, the canonical event record is updated rather than silently preserving a stale date.
