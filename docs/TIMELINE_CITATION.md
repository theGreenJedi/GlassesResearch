# Citing the GlassesResearch Industry Timeline

The Smart-Glasses Industry Timeline is intended to be citable by researchers, journalists, analysts, vendors, and other websites.

## Whole timeline

Preferred citation:

> GlassesResearch. **Smart-Glasses Industry Timeline.** https://glassesresearch.org/docs/INDUSTRY_TIMELINE/

## Individual milestone

Use the event permalink exposed when selecting a graph marker. Canonical events use stable `TL-####` identifiers, for example:

`https://glassesresearch.org/docs/INDUSTRY_TIMELINE/#TL-0004`

When a factual claim depends on a particular announcement, specification, or regulatory fact, cite both the GlassesResearch event and the underlying source listed in the event detail.

## Machine-readable reuse

Canonical event data:

`https://glassesresearch.org/timeline/events.json`

Automatically discovered provisional signals:

`https://glassesresearch.org/timeline/auto-events.json`

Provisional `AUTO-*` identifiers are intentionally not stable historical citations. Only `TL-####` events are canonical.

## Attribution

If reusing the timeline data or rendering your own visualization from it, attribute the dataset to **GlassesResearch** and link to the canonical timeline page. Source-specific licensing and copyright remain with the underlying source owners.
