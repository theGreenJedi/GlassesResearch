# Comparison Engine

GlassesResearch is building a device comparison system that separates **research facts** from **comparison presentation**.

The engine exists now; model comparison data will be populated in later research PRs.

## Current state

- Canonical comparison schema: [`comparisons/schema.json`](../comparisons/schema.json)
- Stable field-level evidence states: `hands-on`, `community`, `primary`, `unknown`
- Explicit unknown handling: missing research is rendered as **Unknown**, never silently converted to false or unsupported
- Validator and normalizer: `scripts/build_comparison_engine.py`
- Future model records: `comparisons/data/GLS-####.json`

## Why the data is intentionally empty

PR #40 establishes infrastructure only. Publishing real comparison values in the same change would make it difficult to distinguish schema design from evidence review.

Later research PRs can add one or more model records, each with field-level sources. The engine can then normalize those records against the same schema without special-case comparison pages.

## Planned output

Once comparison data is populated, the site can render any selected models side-by-side using the same field order and evidence vocabulary. A missing field stays visible as **Unknown** so the comparison also exposes where research is incomplete.

No rankings, winners, or purchase recommendations are generated by the engine itself.
