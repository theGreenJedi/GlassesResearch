## How to use it

Choose two devices above. The comparison updates immediately, highlights differing values, and exposes supporting source links where available.

The URL records the selected pair, so a comparison can be shared directly. The print control produces a cleaner printable view.

## What the engine shows

- one canonical comparison schema across devices;
- field-level source links;
- shareable pair URLs;
- print-friendly output;
- highlighted differences without declaring a winner.

A manufacturer omission is not treated as proof that a feature is absent. Conflicting credible sources remain visible when relevant. See [Research Standards](RESEARCH_STANDARDS.md).
