# Report Card Research Batch 04

This batch applies the catalog-wide benchmark rubric and report-card-first pipeline to Amazon's screenless smart-audio lineage. Scores use the same 0–10 ruler as every other model in the catalog.

## GLS-0009 — Amazon Echo Frames (1st Gen)

**Canonical check:** no correction required. The listing correctly treats the original 2019 Echo Frames as prescription-ready, display-free, camera-free smart audio glasses built around Alexa.

**Evidence basis:** Amazon introduced the first Echo Frames through the Day 1 Editions program as lightweight all-day glasses with hands-free Alexa, open-ear audio, microphones, temple controls, phone notifications, prescription readiness, and explicitly no camera or display.

| Dimension | Score | Grade | Evidence-based judgment |
|---|---:|:---:|---|
| Hardware | 5.5 | C- | Purpose-built microphones, open-ear audio and controls were well integrated for the time, but the device intentionally omitted camera, display and substantial on-frame compute. |
| Wearability | 8.5 | A- | Designed from the beginning to resemble normal prescription-ready eyewear and support all-day wear. |
| Visual AI | N/A | N/A | No outward-facing camera; scene understanding is not part of the hardware architecture. |
| Software | 6.5 | C+ | Alexa, notifications and phone-linked audio created a coherent consumer experience, but the usable software surface was tightly bounded by Amazon's ecosystem. |
| Display / HUD | N/A | N/A | No visual display. |
| Openness | 2.5 | F | No public general-purpose SDK, firmware source, protocol documentation or low-level owner-development path is documented for the glasses. |
| Owner Control | 3.0 | F | Owners can configure Alexa and notifications but cannot meaningfully replace the assistant, firmware or platform stack. |
| Cloud Independence | 2.5 | F | The defining intelligence is Alexa and therefore materially service-dependent; the glasses remain useful as audio hardware only within a paired-phone ecosystem. |
| Hackability | 2.5 | F | Little supported experimentation surface beyond ordinary consumer configuration and Bluetooth use. |
| Value | Not yet graded | — | Historical launch pricing is known, but a durable value score should not be assigned without a contemporaneous used-market comparison. |
