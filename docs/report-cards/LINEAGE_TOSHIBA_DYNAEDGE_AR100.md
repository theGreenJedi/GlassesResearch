# Lineage Research — Toshiba / Dynabook dynaEdge AR100

**Research date:** 2026-08-12

This packet applies the lineage-first protocol to Toshiba/Dynabook's dynaEdge AR Smart Glasses family. The surviving first-party record supports one clear smart-glasses generation centered on the **AR100 head-mounted display paired with the DE-100 mobile mini PC**. Later Vision DE Suite software revisions and mounting options are software/accessory evolution, not separate glasses generations.

## Lineage finding

### dynaEdge AR100 + DE-100 — admit to THE_LIST

The AR100 crossed the repository's acquisition threshold decisively. Dynabook's surviving developer-kit page provides an explicit order workflow, credit-card purchase process, and two complete kits priced at **$2,399.99** and **$2,899.99**. Dynabook also documents an earlier starting price of **$1,899.99** for the complete AR solution. This is therefore a documented commercial enterprise/developer product, not merely a concept or trade-show demo.

The architecture is unusual and important: the **47 g AR100 HMD** is not a standalone computer. It connects by USB-C to the **DE-100 waist-mounted Windows 10 Pro mini PC**, which provides Intel x86 compute, up to 16 GB RAM, M.2 SSD storage, Wi-Fi/Bluetooth, microSD expansion, TPM security and configurable controls. The HMD contributes a 640×360 PixelPure display (1280×720 content resolution), 5 MP autofocus camera with 1080p30 capture, speaker, dual microphones, touchpad/buttons, proximity/ambient-light sensors, gyroscope, accelerometer, compass and GPS.

Dynabook sold multiple mounting configurations—lens-less frame, safety frame, helmet mounts and headband—and its support site records prescription-lens compatibility for the safety-glasses frame. The AR100 itself is IP63 when fitted with the cable-connector cover.

### Vision DE Suite 1.x → 2.0 → 3.0 — software evolution, not new hardware generations

Dynabook's first-party support and press material documents multiple Vision DE Suite revisions. Version 2.0 added voice commands and enhanced camera functions; version 3.0 added task-flow creation/assignment/reporting while preserving document viewing, live video, see-what-I-see, capture, alerts/messaging, workflow instruction and barcode-scanning functions. These revisions materially affect Software capability over time but do not justify separate model rows.

### Developer platform

Dynabook's developer-kit page states that the kits include a **complete reference SDK** for specialized application development. Because the compute unit is a Windows 10 Pro PC rather than a sealed mobile appliance, developers also inherit the broader Windows application environment. This meaningfully improves Owner Control and Hackability compared with vendor-assistant-bound consumer glasses, but the proprietary HMD hardware/firmware and vendor software stack keep Openness well below the Monocle/Frame benchmark.

### Common-ruler rationale

- **Hardware 7.5:** strong enterprise sensing, camera/audio, Windows-class compute, storage and security, but split-body architecture, aging 6th-gen Intel silicon and low-resolution optics keep it below modern best-in-catalog systems.
- **Wearability 4.5:** the 47 g HMD is light, but true use requires a cabled 310 g waist-mounted PC. Multiple mounts and prescription-compatible safety frames help, but this is clearly industrial equipment rather than ordinary eyewear.
- **Visual AI N/A:** the camera and sensors support inspection, barcode scanning and remote expert workflows, but the evidence does not establish an integrated visual-AI understanding stack comparable with current AI glasses.
- **Software 7.5:** Windows 10 Pro, Vision DE Suite, partner software and task-flow/voice functions create a substantial enterprise software surface. The aging/discontinued ecosystem and proprietary Vision layer prevent a higher score.
- **Openness 6.0:** a complete reference SDK and general Windows application environment provide real development access, but firmware, HMD electronics and optical hardware remain proprietary.
- **Owner Control 8.0:** owners can run Windows applications, use third-party enterprise software, access files locally and develop custom applications rather than being confined to a single vendor assistant.
- **Cloud Independence 9.0:** core Windows applications, local documents, camera capture and many workflow functions can operate without a mandatory Dynabook cloud. Cloud services are optional depending on the chosen remote-expert application.
- **Hackability 6.5:** Windows plus SDK access make experimentation practical, but USB-attached proprietary HMD hardware and closed firmware keep it far below open-hardware platforms.
- **Display/HUD 6.5:** 640×360 see-through monocular output is useful for instructions and remote-work overlays but modest by the catalog's present display ceiling.
- **Value 5.0:** roughly $1,900–$2,900 bought a complete enterprise wearable Windows system and SDK, but the split architecture and limited optics made it expensive relative to both later monocular devices and modern XR displays.

## Boundary conclusion

For catalog purposes this lineage is **one glasses model generation**: AR100 HMD + DE-100 compute system. Variants in processor/storage, frame/mount style, and Vision DE Suite version are configuration/software differences rather than separate smart-glasses generations. No evidence in the surviving first-party record supports a later AR200-class commercial successor, so the lineage ends here unless archival research uncovers a materially distinct shipped generation.
