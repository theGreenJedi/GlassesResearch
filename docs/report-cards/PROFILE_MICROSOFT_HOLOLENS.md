# Evidence-derived profiles — Microsoft HoloLens

## HoloLens (1st gen)

The first HoloLens is best understood as a self-contained spatial computer worn on the head, not as smart glasses. Its waveguide display, depth/environment cameras, custom HPU and Windows Holographic platform made local spatial mapping and holographic applications possible without tethering to a PC. That earns exceptional display, software and cloud-independence marks for its era, but the 579 g headset form keeps wearability near the bottom of an eyewear-centered catalog.

## HoloLens 2

HoloLens 2 deepened the same architecture rather than chasing ordinary-eyeglass form. Eye tracking, fully articulated hand tracking, ToF depth sensing, richer cameras, Snapdragon compute and a second-generation HPU made it a far more capable enterprise spatial-computing system. Its developer surface is broad and owner-deployed apps can run locally, but the platform remains proprietary and initial setup requires Microsoft's account/network ecosystem. It belongs prominently in the broader wearable-HCI museum while remaining clearly separated from actual glasses.
