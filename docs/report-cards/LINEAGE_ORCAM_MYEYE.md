# Lineage Research — OrCam MyEye

**Research date:** 2026-08-12

## Lineage finding

OrCam MyEye is an assistive wearable-camera lineage that attaches magnetically to ordinary eyeglass frames and converts visual information into audio. The strongest surviving evidence supports a modern MyEye 2 / MyEye 2 Pro generation and the newer MyEye 3 Pro. Earlier MyEye hardware clearly existed, but model-level primary specifications are too incomplete in the current evidence package to assign a separate numeric report card without archival recovery.

### MyEye 2 / MyEye 2 Pro

OrCam documents MyEye 2 as a tiny wearable AI device for blind and low-vision users that reads text and recognizes faces, products, colors, currency and other visual information. Current product material lists MyEye 2 Pro at $4,250 and describes a 22.5 g wearable module with roughly 1.5–2 hours active use. OrCam's own materials repeatedly emphasize local/offline operation for core recognition tasks, an unusual strength for a camera-AI wearable.

### MyEye 3 Pro

MyEye 3 Pro is the current successor and keeps the same eyeglass-mounted form while adding Smart Magnifier and an interactive AI assistant. Current pricing is $4,490 list / $4,250 promotional in the US comparison page. Core reading, face/product/currency/color recognition and many assistive functions remain native to the wearable, while the newer interactive assistant can use outside data and therefore introduces optional network dependence beyond the historically offline recognition stack.

### Common-ruler rationale

- **Wearability 9.0:** the 22.5 g module attaches to ordinary glasses and is much less physically intrusive than headset-style assistive devices.
- **Visual AI 8.0–8.5:** text, face, product, currency and color recognition are central native functions rather than generic camera capture; MyEye 3 adds a more interactive AI layer.
- **Software 8.0–8.5:** unusually mature assistive workflows and voice/gesture interaction, but within a closed vendor stack.
- **Openness/Hackability 2.0:** no meaningful public SDK, firmware source or replaceable-AI surface was found.
- **Owner Control 6.5:** users have strong direct control over the device's assistive functions, but not over the underlying software/AI implementation.
- **Cloud Independence:** MyEye 2's core recognition model is notably offline; MyEye 3's optional interactive assistant can depend on external data, so its score is slightly lower.
- **Display/HUD N/A:** MyEye communicates primarily through audio and does not provide a visual HUD.
- **Value 4.0:** the functionality is substantial, but current pricing above $4,000 is expensive relative to the broader wearable catalog.
