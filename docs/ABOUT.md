# About GlassesResearch

GlassesResearch is an independent, vendor-neutral research institution for smart glasses, AI eyewear, and wearable computing.

The public site leads with research. This page gathers the mission, operating principles, evidence rules, privacy promise, preservation methods, and project governance for readers who want to understand how the work is organized.

## Preservation and scope

- [Preservation Program](PRESERVATION_PROGRAM.md)

GlassesResearch covers current, historical, discontinued, obscure, industrial, experimental, white-label, and unsuccessful devices. The W610 is the current hands-on reference device, not the boundary of the project.

## Privacy

- [Privacy statement](PRIVACY.md)

The site uses no project-added advertising, tracking cookies, behavioral profiling, or sale of visitor data. Community greetings rely only on an explicit `?from=` value in a shared link and are not retained.
