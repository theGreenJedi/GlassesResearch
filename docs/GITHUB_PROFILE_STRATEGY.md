# GitHub Profile Strategy

The profile should present Pete as a trusted technical operator, investigator, teacher, and steward of durable engineering knowledge—not as a collector of unrelated repositories.

## Intended impression

- Calm competence
- Systems thinking
- Evidence-led investigation
- Infrastructure and hardware fluency
- Operational discipline
- Teaching and knowledge preservation
- User-controlled, open technology

## Profile README structure

1. One-sentence identity
2. Current flagship work
3. Areas of practice
4. Operating principles
5. Selected repositories
6. How to collaborate or contact

## Draft positioning

> Infrastructure operator and systems investigator documenting how complex technology actually works—from data-center operations and resilient systems to open smart-glasses research.

## Pin strategy

Use pins as a curated portfolio, not a recency list.

1. `GlassesResearch` — flagship research and documentation project
2. Future `OpenW610` — polished public reference if separated from the laboratory repository
3. A strong infrastructure or automation repository
4. A teaching or field-guide repository
5. A polished hardware, networking, or sovereign-computing project
6. One representative utility or experimental project

## Repository presentation standard

Every pinned repository should have:

- Clear description and topics
- Purpose-driven README
- Current status
- Screenshots or diagrams where useful
- License and contribution guidance
- Reproducible setup or methodology
- Honest limitations
- Archived status when no longer maintained

## Visual identity

Prefer simple diagrams, restrained badges, readable typography, consistent naming, and evidence-oriented language. Avoid promotional clutter, excessive metrics, and unsupported claims.
