# Pull-request intent

This resource set addresses the preservation gap between discovering a useful ecosystem link and converting it into durable, provenance-rich research.

It affects the W610 plus cross-model SDK, firmware, protocol, hardware, developer-platform, and community-resource layers. Entries are explicitly labeled as hands-on, project-primary, community, commercial, or inference; no externally sourced resource is presented as project-tested.

The initial merge records canonical links and a preservation queue. It does not mirror restricted or license-uncertain artifacts. Future preservation work should add retrieval metadata, hashes, licensing, and redistribution status before storing downloadable files.
