# Resource Preservation Checklist

Use this checklist when a useful external artifact is discovered.

- [ ] Identify the canonical source and owner.
- [ ] Record every affected model or platform.
- [ ] Classify the evidence lane: hands-on, project-primary, community, commercial, or inference.
- [ ] Record retrieval time, version/revision, license, and redistribution status.
- [ ] Download only when lawful and useful.
- [ ] Hash the untouched original before analysis.
- [ ] Keep modified, decoded, patched, or converted derivatives separate from the original.
- [ ] Record required tools, credentials, hardware, region, and app dependencies.
- [ ] Note whether the source is fragile, login-gated, region-limited, discontinued, or likely to disappear.
- [ ] Add the resource to the ecosystem catalog or the appropriate model chapter.
- [ ] Cross-link recurring organizations, applications, chipsets, protocols, and repositories to canonical homes.
- [ ] Preserve corrections and dead-link history rather than silently replacing evidence.

A link by itself is intake, not preservation. When redistribution is restricted or uncertain, preserve metadata, hashes, acquisition instructions, and analysis notes without republishing the artifact.
