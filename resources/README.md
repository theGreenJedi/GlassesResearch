# Ecosystem Resources

This directory contains cross-model resource discovery and preservation work.

- [Smart-Glasses Ecosystem Resource Catalog](ECOSYSTEM_RESOURCE_CATALOG.md) — substantive starting catalog for SDKs, firmware, protocols, hardware projects, developer platforms, and fragile artifacts.

Model-specific resources remain inside their model chapters. For example, W610-specific material belongs under [`models/W610/resources/`](../models/W610/resources/). Cross-model resources live here until evidence supports promotion into one or more dedicated model chapters.
