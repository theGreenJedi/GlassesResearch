# Visual Evidence Archive

This directory preserves photographs, screenshots, diagrams, and scans that support the written research record.

## Folder structure

Group related evidence into dated folders:

```text
images/YYYY-MM-DD-topic/
```

Examples:

```text
images/2026-08-03-unboxing/
images/2026-08-04-ble-discovery/
images/2026-08-10-frame-measurements/
```

Each folder should include a `README.md` that catalogs every file and explains its relevance.

## File naming

Use descriptive lowercase names separated by hyphens:

```text
amazon-listing.jpg
packaging-front.jpg
right-arm-buttons.jpg
manual-page-01.jpg
ble-scan-services.png
```

Avoid generic camera names such as `IMG_1234.jpg` whenever practical. Preserve the original file separately if renaming would discard useful metadata.

## Provenance

For every image, record:

- Whether it is an original photograph, screenshot, scan, vendor image, or community-supplied image
- Capture or retrieval date
- Source or marketplace
- What the image demonstrates
- Any editing, cropping, redaction, or annotation

Third-party images should include attribution and a source reference. Do not imply that a vendor image is an original device photograph.

## Evidence integrity

- Preserve an unedited original when possible.
- Put annotated or cropped derivatives beside the original and label them clearly.
- Do not silently alter evidence.
- Record uncertainty when an image does not conclusively establish a claim.
- Prefer multiple angles for physical details.

## Privacy and security review

Before committing an image, check for:

- Personal names, addresses, order numbers, and shipping labels
- Bluetooth MAC addresses or device identifiers that should not be public
- Wi-Fi names, passwords, QR credentials, tokens, and account information
- Reflections, computer screens, browser tabs, notifications, and location clues
- Copyright or redistribution restrictions

Redact only what is necessary and disclose the redaction in the folder index.

## Relationship to the research log

Link each evidence set from [`../docs/ResearchLog.md`](../docs/ResearchLog.md). The log records the session and conclusions; the image folder preserves the supporting visual record.
