# Verified Changes

Stable `GRE-*` records identify verified changes that have already crossed the GlassesResearch publication boundary.

The production site build generates this directory from the canonical verified-change ledger. Discovery candidates and **Watching** items are excluded. Each generated change record links back to the corresponding published research and, when applicable, the exact affected canonical model or relationship.
